Violation of CIS-NET-004 & NIST SP 800-53 SC-8

Telnet transmits administrative login credentials, challenge keys, and command buffers over unencrypted cleartext TCP port 23. This exposes session data to packet sniffing, credential interception, and automated man-in-the-middle takeovers.

Standard Remediation Recipe:
check_circle Ensure SSHv2 with 2048-bit RSA or Ed25519 host keys is configured prior to disabling Telnet service.
check_circle Apply ACL filter to management VTY lines restricting administrative access strictly to approved Bastion CIDRs.
check_circle Execute transport input ssh on all terminal lines.
